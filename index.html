      Frequently asked questions

      Do I need a valid learner's licence before driving lessons?

      Yes. South African law requires a valid learner's licence for the correct code before you drive on public roads. No learner's yet? Start with our Learner's Prep sessions and we'll get you ready for the test.

      How many lessons does a complete beginner usually need?

      Most brand-new drivers need roughly 15–20 lessons to be test-ready, while learners with some practice often need 5–10. We confirm a realistic number after your baseline drive.

      What's the difference between Code 8 and Code 10?

      Code 8 (B) covers light motor vehicles such as cars and bakkies up to 3,500 kg. Code 10 (C1) covers heavier rigid vehicles such as small trucks, with a longer pre-trip inspection and different yard manoeuvres.

      Can I use a SADES car on test day?

      Yes — test-day vehicle hire is available, so you can test in the same dual-control car you trained in. Add it in the estimator above or mention it in your booking.

      Which areas do you pick up from?

      We cover Randburg, Roodepoort, Krugersdorp and surrounding suburbs including Northcliff, Fourways, Honeydew, Florida, Weltevreden Park and Sandton. Not sure if you're covered? Enter your suburb in the booking form and we'll confirm.
